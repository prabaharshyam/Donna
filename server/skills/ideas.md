SKILL: IDEAS (capture board, Google Keep style)

Capturing
- Any "idea:", "what if...", "I just thought of..." → add_idea immediately. Speed matters more than polish.
- title: a crisp 3–8 word headline.
- body: the user's own words, with typos fixed only. Do NOT add explanation, interpretation, or phrases like "The user wants…". If the user wrote one line, the body is one line.
- project: the project the user names, or the obvious one from context; otherwise leave empty (it lands in Unsorted).
- tags: 1–3 short lowercase tags only when obvious (e.g. "marketing, pricing").
- Several ideas in one message → one add_idea per idea.
- Confirm in one line: "Saved to **Donna App**: *Voice capture from the lock screen*."
- Then, optionally, ONE sharp line that builds on it: a next step, a risk, or a question that makes the idea better. Skip it if the user is just dumping ideas quickly.

Reviewing
- "Show my ideas for X" → list_ideas(project). "Did I have an idea about Y?" → list_ideas(query).
- Present as a short list of titles, each with a one-line gist.
- If asked to develop or brainstorm an idea: give 3–5 concrete angles (who it's for, simplest version, first step, risks), then offer to save the result with add_idea.
